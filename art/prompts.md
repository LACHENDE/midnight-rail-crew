# 銀河鉄道 Galaxy Rail Crew: ChatGPT image prompts

These images replace the greybox shapes in the game.

## How to use
1. Open **one new ChatGPT chat** and make every image in it. Images stay consistent better that way.
2. Attach `shiba-reference.png` (in this folder), then paste the **Style block** first.
3. Paste the prompts one at a time, in the priority order below. ★ = do these first.
4. Download each image as **PNG** and save it with the exact file name into `games/rail-crew/art/`. Then tell Claude, and it will convert the images and put them in the game.
5. If an image has any text, letters or numbers in it, reply: *"Same image, but remove all text, letters and numbers."* The game draws all the Japanese itself.
6. Objects must have a **transparent background**. If one comes back with a background, reply: *"Same image on a fully transparent background, PNG."*

The free plan allows only a few images a day, so this can take several days. The ★ images alone already make it look like a real game.

## Style block (paste first, with `shiba-reference.png` attached)

```
I'm making art for a cute co-op mobile game for kids learning Japanese: "Galaxy Rail Crew", a magical old steam train flying through a starry night sky over Japan (inspired by the feeling of Night on the Galactic Railroad, but my own original design). Use this style for every image I ask for in this chat:
- Flat 2D cartoon sticker style like the attached shiba: thick dark-brown outlines (#2A211B), clean shapes, soft simple shading, warm and cosy. No photorealism, no 3D render look.
- Camera: top-down three-quarter view (looking down at about 60 degrees), like a cosy top-down co-op cooking game. Every image uses this same angle.
- Palette: deep night blue and indigo, warm lantern amber, deep red train paint, brass, cream. Japanese touches: paper lanterns, shoji-style panels, wooden floors, little shimenawa ropes.
- Spooky-cute when there are spirits: friendly, never scary for a small child.
- Never put any text, letters, numbers, kanji or symbols in the images.
Reply "ready" and wait for my first image.
```
